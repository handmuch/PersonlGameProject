## 后续更新方式

每次完成一个可明确描述的学习或开发阶段时：

1. 在本目录新增 `YYYY-MM-DD-主题.md`。
2. 更新本页的记录列表。
3. 将累计成果同步到 `../DEVELOPMENT_SUMMARY.md`。
4. 在根目录 `README.md` 中只保留简短的当前进度和下一步。

单次记录建议包含：本次目标、学习内容、实现内容、文件变化、验证结果、问题与下一步。
