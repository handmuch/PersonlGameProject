# 项目开发总结

本文档记录项目方向、技术选择和累计开发成果。每次完成一个学习阶段或功能后，在这里更新整体状态，并在 `development-log` 中新增一篇详细记录。

## 项目目标

制作一款可发布到 Steam 的俯视角 2D 像素动作游戏。玩法方向参考《Death Road to Canada》的即时战斗与生存探索体验，但会从小规模、可验证的个人项目开始逐步扩展。

第一阶段的目标是完成一个小型战斗原型：玩家可以在房间内移动、攻击丧尸、拾取物资并到达撤离点。

## 技术方案

| 项目 | 当前选择 | 用途 |
| --- | --- | --- |
| 游戏引擎 | Godot 4 | 场景、角色、物理、动画、UI 和游戏逻辑 |
| 脚本语言 | GDScript | 编写玩家、敌人和游戏系统逻辑 |
| 美术工具 | Aseprite | 制作像素角色、动画、武器和地图图块 |
| 版本管理 | Git + GitHub | 保存版本、同步代码和记录开发过程 |
| 目标平台 | Windows / Steam | 首要发布目标；日常可在 macOS 开发 |

## 当前工程结构

Godot 工程位于 `my-demo/`：

- `project.godot`：工程设置和启动场景配置。
- `main.tscn`：当前主场景。
- `icon.svg`：项目默认图标。
- `.gitignore`：排除 `.godot/` 等本地生成内容。

当前主场景的节点结构：

```text
Main
├── Player (CharacterBody2D)
│   ├── AnimatedSprite2D
│   ├── CollisionShape2D
│   ├── AudioStreamPlayer2D
│   └── Camera2D
└── Label (Hello World)
```

`Player` 使用 `CharacterBody2D`，为后续通过脚本控制移动并参与物理碰撞做好准备。显示、碰撞、声音和摄像机分别使用独立子节点，便于后续逐项补充资源和配置。

## 当前状态

工程已经具备继续开发的基础场景结构，但还不是可玩的游戏原型。当前没有 `.gd` 脚本，玩家节点尚未配置精灵帧和碰撞形状，移动、攻击、敌人及物资系统也尚未实现。

## 开发路线

1. 实现玩家八方向移动和基础输入映射。
2. 添加玩家占位图、动画切换与碰撞。
3. 搭建包含墙体和障碍物的测试房间。
4. 实现一种近战武器及攻击判定。
5. 实现一种会追踪、攻击和死亡的丧尸。
6. 添加生命值、物资拾取和撤离点，形成首个完整循环。

在核心战斗体验得到验证后，再考虑队友 AI、尸群优化、随机地图和公路事件。
